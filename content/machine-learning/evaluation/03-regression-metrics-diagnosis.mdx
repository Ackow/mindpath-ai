## 1. 回归模型到底应该怎样评价？

回归模型输出连续数值，例如房价、温度、销量和交付时间。分类中的“预测对或错”不再适用，我们需要衡量预测值与真实值之间相差多少，以及误差是否存在系统性偏向。

一个模型平均误差很小，并不代表所有样本都预测得好；同样，一个模型的 R² 较高，也不代表它满足业务对最大误差的要求。

## 2. 四个核心回归指标

设真实值为 $y_i$，预测值为 $\hat y_i$，样本数为 $n$。

### 2.1 MAE：平均绝对误差

$$
MAE = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat y_i|
$$

MAE 的单位与目标变量相同，直观表示“平均差多少”。它对异常值相对不敏感，适合需要稳定平均误差的场景。

### 2.2 MSE：均方误差

$$
MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat y_i)^2
$$

MSE 会放大较大的错误。如果业务特别不能接受少数极端偏差，MSE 很有用；但它的单位是目标单位的平方，解释性不如 MAE 直观。

### 2.3 RMSE：均方根误差

$$
RMSE = \sqrt{MSE}
$$

RMSE 与目标变量使用相同单位，同时保留了对大误差的惩罚。需要注意，RMSE 仍然会被少数异常值明显影响。

### 2.4 R²：解释方差的比例

$$
R^2 = 1 - \frac{\sum_i(y_i - \hat y_i)^2}{\sum_i(y_i - \bar y)^2}
$$

R² 衡量模型相对于“永远预测均值”的改进程度。R² 越接近 1 通常越好，但在测试集上出现负数并不矛盾，它表示模型还不如均值基线。

## 3. 指标如何选择？

| 业务关注点 | 推荐指标 |
|---|---|
| 平均误差是否容易解释 | MAE |
| 极端大误差必须被重罚 | MSE 或 RMSE |
| 需要与目标单位保持一致 | MAE 或 RMSE |
| 与均值基线比较解释力 | R² |
| 异常值很多 | MAE，并单独分析异常样本 |
| 需要满足误差上限 | MAE + 最大误差分位数 |

不要把 R² 当成唯一指标。最好同时报告 MAE、RMSE 和 R²，并结合业务单位解释。

## 4. Python 实战：统一输出回归指标

<RunnableCodeBlock title="回归模型多指标评估" language="python">
{`from sklearn.datasets import load_diabetes
from sklearn.linear_model import Ridge
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.model_selection import train_test_split
import numpy as np

data = load_diabetes()
X_train, X_test, y_train, y_test = train_test_split(
    data.data, data.target, test_size=0.2, random_state=42
)

model = Ridge(alpha=1.0)
model.fit(X_train, y_train)
pred = model.predict(X_test)

mae = mean_absolute_error(y_test, pred)
rmse = np.sqrt(mean_squared_error(y_test, pred))
r2 = r2_score(y_test, pred)

print(f"MAE : {mae:.2f}")
print(f"RMSE: {rmse:.2f}")
print(f"R2  : {r2:.3f}")
`}
</RunnableCodeBlock>

## 5. 模型诊断：不要只看一个总分

### 5.1 训练集与验证集差距

- 训练误差很小，验证误差明显更大：可能过拟合；
- 训练误差和验证误差都很大：可能欠拟合、特征不足或数据质量差；
- 两者都很小但上线很差：可能存在数据泄漏或训练/线上分布变化。

### 5.2 残差分析

残差定义为：

$$
 e_i = y_i - \hat y_i
$$

观察残差时，可以检查：

- 残差均值是否接近 0；
- 残差是否随着预测值增大而扩大；
- 某些特征区间是否持续高估或低估；
- 是否存在明显的周期性、分群或异常点。

如果残差呈现明显结构，说明模型还没有学到数据中的规律。

### 5.3 学习曲线

学习曲线比较不同训练样本量下的训练分数和验证分数，常用于判断继续收集数据是否有帮助：

- 两条曲线都差且接近：偏差较高，模型可能欠拟合；
- 训练分数高、验证分数低且差距大：方差较高，模型可能过拟合；
- 随着数据增加验证分数持续提升：增加数据可能有效。

## 6. 交叉验证中的回归评估

```python
from sklearn.model_selection import KFold, cross_validate
from sklearn.linear_model import Ridge

cv = KFold(n_splits=5, shuffle=True, random_state=42)
result = cross_validate(
    Ridge(alpha=1.0),
    X, y,
    cv=cv,
    scoring=["neg_mean_absolute_error", "neg_root_mean_squared_error", "r2"]
)

mae = -result["test_neg_mean_absolute_error"]
rmse = -result["test_neg_root_mean_squared_error"]
print(f"MAE: {mae.mean():.2f} +/- {mae.std():.2f}")
print(f"RMSE: {rmse.mean():.2f} +/- {rmse.std():.2f}")
print(f"R2: {result['test_r2'].mean():.3f}")
```

Scikit-Learn 中以 `neg_` 开头的损失指标是为了遵循“分数越大越好”的统一接口，因此取负号后才是通常意义上的 MAE 或 RMSE。

## 7. 常见诊断陷阱

- 只看平均指标，不看误差分布；
- 在不同目标尺度的数据集之间直接比较 RMSE；
- 忽略异常值对 MSE 和 RMSE 的影响；
- 把高 R² 直接理解为因果关系；
- 随意删除误差最大的样本，而不调查它们是否代表真实业务；
- 没有使用时间切分，却把未来样本随机混入训练集。
