# 05. 函数与作用域

函数是代码重用与抽象的核心载体。

<RunnableCodeBlock title="可变参数与高阶函数">
{`def apply_transform(data, transform_fn):
    return [transform_fn(x) for x in data]

square = lambda x: x ** 2
print(apply_transform([1, 2, 3, 4], square))`}
</RunnableCodeBlock>
