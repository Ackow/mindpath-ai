# 03. 控制流与推导式

推导式 (Comprehension) 是 Python 最具特色的 Pythonic 简洁语法。

<RunnableCodeBlock title="列表推导式与条件筛选">
{`data = [1.2, -0.5, 3.4, -2.1, 0.8]
# 相当于激活函数 ReLU
relu_output = [x if x > 0 else 0 for x in data]
print("ReLU 模拟滤波:", relu_output)`}
</RunnableCodeBlock>
