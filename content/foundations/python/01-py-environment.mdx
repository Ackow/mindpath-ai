## 1. 问题导入

为什么全世界 90% 以上的数据分析师和人工智能工程师，都选择 **Python** 作为第一门编程语言？

答案非常简单：**优雅、简洁、像英语一样自然**。在其他语言中打印一段文字可能需要 5 到 10 行模板代码，而在 Python 中只需一行：

```python
print("Hello, World!")
```

但在开始写代码前，我们面临的第一关就是**搭建一个稳定、独立、不踩坑的 Python 开发环境**。如果环境没配好，经常会出现“明明安装了包却提示找不到”、“不同项目依赖版本冲突”等头疼问题。

本章将手把手带你理解 Python 环境构成、完成 Python 安装与虚拟环境隔离，并掌握数据科学领域最受欢迎的交互式工具 —— **Jupyter Notebook**！

- 在 VS Code 中正确选择项目解释器，并使用 `python -m pip` 安全安装依赖包；

- 识别并独立排查环境找不到、中英文标点、变量未定义等初学者高频报错。

## 3. 理解四大核心概念

开始配置前，我们先建立对 Python 开发环境的直觉认知：

| 核心概念 | 它是什么 | 生活比喻 | 你会用它做什么 |
|---|---|---|---|
| **Python 解释器** | 执行 Python 代码的电脑程序 | **实验设备引擎** | 运行 `.py` 脚本、翻译代码给电脑 |
| **`pip` 包管理器** | Python 官方的第三方扩展库安装工具 | **材料采购工具** | 安装 NumPy、Pandas、Matplotlib 等工具库 |
| **虚拟环境 (`venv`)** | 项目专属、相互隔离的 Python 目录 | **专属独立实验室** | 避免不同项目之间的工具包版本冲突 |
| **Jupyter Notebook** | 基于网页的交互式开发与实验文档 | **实验记录本** | 逐格运行代码、查看可视化图表与笔记 |

<ConceptCard title="环境配置第一原则：一项目一虚拟环境" type="intuition">
切记：不要把所有的第三方包都一股脑装在电脑全局的 Python 中！每个项目都应该有自己独立的 `.venv` 虚拟环境。这样即使一个项目的包损坏了，也不会影响电脑上的其他项目。
</ConceptCard>

## 4. Python 安装与 PATH 配置

### 4.1 从官网下载与安装
1. 打开 [Python 官方下载页面](https://www.python.org/downloads/)，下载适用于你操作系统的当前稳定版（推荐 Python 3.10 及以上版本）。
2. **最关键的一步**：在 Windows 安装界面底部，**务必勾选 “Add python.exe to PATH”**（将 Python 添加到系统环境变量），然后点击 Install Now。

>  **什么是 PATH？**
> `PATH` 是操作系统的快捷搜索路径。勾选后，系统终端（PowerShell 或 CMD）才能在任意目录下识别并执行 `python` 命令。

### 4.2 验证 Python 是否安装成功
打开终端（Windows 快捷键 `Win + R` 输入 `powershell`，或 Mac/Linux 打开 `Terminal`），输入以下命令并回车：

```powershell
python --version
python -m pip --version
```

**预期输出**：
```text
Python 3.11.x
pip 23.x.x from ...
```
只要能正常显示 Python 和 pip 的版本号，就说明基础环境已经安装成功！

## 5. 为项目创建虚拟环境与安装包

### 5.1 创建项目专属虚拟环境
在终端中切换到你的项目根目录（例如 `F:\Project\AILearning`），运行以下命令：

```powershell
# 在当前目录下创建一个名为 .venv 的独立虚拟环境
python -m venv .venv
```

运行后，你会发现项目文件夹下多出了一个名为 `.venv` 的隐藏目录，里面包含了一套全新的 Python 解释器。

### 5.2 激活虚拟环境
根据你的操作系统，在终端运行激活脚本：

- **Windows PowerShell**:
  ```powershell
  .venv\Scripts\Activate.ps1
  ```
- **Mac / Linux 终端**:
  ```bash
  source .venv/bin/activate
  ```

激活成功后，终端命令行最前方会出现 **`(.venv)`** 前缀标志：

```text
(.venv) PS F:\Project\AILearning>
```

> [!WARNING]
>
> **Windows 提示“禁止运行脚本”怎么办？**
> 如果 PowerShell 提示 `Set-ExecutionPolicy` 相关报错，只需在当前终端运行以下命令 temporary 放宽策略后重新激活即可：
>
> ```powershell
> Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
> .venv\Scripts\Activate.ps1
> ```

### 5.3 为什么推荐使用 `python -m pip`
激活虚拟环境后，安装第三方包时建议使用 `python -m pip` 语法：

```powershell
python -m pip install --upgrade pip
```

使用 `python -m pip` 可以 100% 保证是将工具包安装到**当前 Python 解释器对应的虚拟环境**中，彻底杜绝“装错位置”的隐患。

### 5.4 安装与启动 Jupyter Notebook

确认虚拟环境 `(.venv)` 已激活后，使用 `pip` 显式安装 **Jupyter** 包：

```powershell
# 1. 安装 Jupyter Notebook 及其依赖包
python -m pip install jupyter
```

安装完成后，有两种最常见的启动与使用方式：

#### 方式一：网页版独立启动（浏览器界面）
在激活了 `(.venv)` 的终端中运行以下命令：

```powershell
# 2. 启动网页版 Jupyter Notebook
jupyter notebook
```
运行后终端会启动本地 Web 服务器，并自动在浏览器中打开 `http://localhost:8888` 页面。你可以在网页中点击 `New -> Python 3 (ipykernel)` 新建 Notebook 文档。

#### 方式二：在 VS Code 中集成使用（推荐）
1. 在 VS Code 插件市场搜索并安装 **Jupyter** 插件；
2. 在 VS Code 中新建一个扩展名为 `.ipynb` 的文件（例如 `demo.ipynb`）；
3. 点击编辑器右上角的 **选择 Kernel (Select Kernel)** 按钮，选择刚才创建的 `(.venv)` 解释器。

## 6. VS Code 配置与解释器选择

Visual Studio Code (VS Code) 是目前最主流的代码编辑器。

1. 打开 [VS Code 官网](https://code.visualstudio.com/) 下载并安装；
2. 打开 VS Code，在左侧扩展市场（Extension）中搜索并安装 **Python** 插件与 **Jupyter** 插件；
3. 选择 `文件 -> 打开文件夹`，打开你的项目目录 `F:\Project\AILearning`；
4. 按快捷键 **`Ctrl + Shift + P`**（Mac 上为 `Cmd + Shift + P`），输入并选择：
   ```text
   Python: Select Interpreter
   ```
5. 在弹出的列表中，选择刚才创建的带 `(.venv)` 标识的解释器路径（如 `./.venv/Scripts/python.exe`）。

## 7. Jupyter Notebook 核心操作

在数据科学中，我们最常用的是 Notebook 交互文档（扩展名为 `.ipynb`）。

### 7.1 单元格的两大类型

Notebook 由一个个 **Cell（单元格）** 组成：

1. **Code Cell（代码单元格）**：用于编写并运行 Python 代码，左侧带有 `In [ ]:` 标识；
2. **Markdown Cell（文本单元格）**：用于编写带排版的说明文字、标题与公式。

### 7.2 必须掌握的高频快捷键

| 快捷键 | 功能描述 | 使用场景 |
|---|---|---|
| **Shift + Enter** | **运行当前单元格，并跳转到下一个单元格** | 最常用的代码运行方式 |
| **Ctrl + Enter** | **运行当前单元格，但停留在当前位置** | 调试单行代码 |
| **A** (选中单元格时) | 在当前单元格**上方**插入新单元格 (Above) | 补充前置代码 |
| **B** (选中单元格时) | 在当前单元格**下方**插入新单元格 (Below) | 新增后续代码 |
| **D + D** (双击 D) | **删除**当前单元格 (Delete) | 清理无用代码 |

### 7.3 单元格运行状态标识
单元格左侧的 `In [ ]:` 括号代表了代码执行状态：

- `In [ ]:` —— **未运行**：代码尚未被执行；
- `In [*]:` —— **正在运行**：代码正在计算中（如在处理大数据）；
- `In [1]:` —— **已运行**：数字代表代码在当前会话中被执行的先后顺序。

## 8. 第一行 Python 代码与变量初体验

让我们开始编写真正的 Python 代码！

### 8.1 输出文本与基础计算
`print()` 是 Python 的内置输出函数。要输出文字，需要用**英文双引号 `""` 或单引号 `''`** 包围：

```python
print("欢迎来到 Python 的世界！")
print(10 + 5)  # 输出 15
```

### 8.2 变量赋值
把变量想象成一个“**贴有标签的盒子**”：使用单等号 `=` 把右边的数值放入左边的变量名中：

```python
# 1. 把 18 放入名为 age 的变量盒子里
age = 18

# 2. 把 "小明" 放入名为 user_name 的变量盒子里
user_name = "小明"

# 3. 打印变量
print(user_name)
print(age)
```

## 10. 常见错误排查 (Troubleshooting)

在配置环境与初学代码时，常见的报错与解决排查方案如下：

| 错误现象 / 异常类型 | 常见原因 | 标准排查与处理方式 |
|---|---|---|
| `python : 无法将“python”项识别为 cmdlet...` | 安装 Python 时未勾选 **Add python.exe to PATH** | 重新运行 Python 安装包，选择 Modify，补勾选 PATH 选项并重启终端 |
| `ModuleNotFoundError: No module named 'xxx'` | 第三方包未安装，或者装到了全局环境而非当前 `.venv` 中 | 确认终端前有 `(.venv)` 标志，运行 `python -m pip install 包名` |
| `SyntaxError: invalid character` | 误用了**中文标点符号**（如中文双引号 `“”` 或中文括号 `（）`） | 切换为英文输入法，将所有引号、括号、逗号替换为**英文半角字符** |
| `NameError: name 'xxx' is not defined` | 调用的变量名拼写错误，或定义该变量的单元格**尚未运行** | 检查变量拼写与大小写；确保上方定义变量的代码单元格已按 `Shift+Enter` 运行 |
| `无法加载文件...因为在此系统上禁止运行脚本` | Windows PowerShell 默认禁止运行 `.ps1` 激活脚本 | 在终端运行 `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` 临时放宽限制 |
