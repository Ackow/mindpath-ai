## 从一个问题开始

在真实的 AI 与数据科学工程中，数据很少以干净的 NumPy 纯数字矩阵直接呈现。真实数据往往是包含姓名、日期、省份、分类标签与缺失值的**异构表格 (Tabular Data)**。

NumPy 擅长高密度的纯数字矩阵运算，但面对字符串列、缺失值 `NaN` 和按列名检索时却力不从心。

这正是 **Pandas** 登场的时刻！把 Pandas 比作 Python 中的“超级 Excel 引擎”：它不仅能以极高效率读取 GB 级别的 CSV/Excel 文件，还能用极其简洁的代码完成数据清洗、条件筛选、多表关联与分组统计。

<ConceptCard title="初学者直觉：Pandas DataFrame 物理三要素" type="tip">
一个 `pd.DataFrame` 相当于附带了额外坐标轴信息的二维表格：
- **`Index` (行索引)**：每行数据的唯一身份标识（如 0, 1, 2... 或时间日期）。
- **`Columns` (列名/表头)**：每列数据的语义标签（如 `'age'`, `'price'`, `'city'`）。
- **`Values` (底层的 NumPy 数组)**：真正存储底层数值、文本与数据的二维矩阵。
</ConceptCard>

## 1. 核心数据结构：Series 与 DataFrame

Pandas 建立在两大核心数据结构之上：

1. **`pd.Series`**：一维带索引的序列（类似于附带了行标签的一维数组或单列数据）。
2. **`pd.DataFrame`**：二维带行索引和列名的表格（可看作由多个共享相同 Index 的 Series 拼接而成的字典）。

<RunnableCodeBlock title="代码实战：创建 Series 与 DataFrame">
{`import pandas as pd
import numpy as np

# 1. 创建一维 Series
s = pd.Series([88, 92, 79], index=['Alice', 'Bob', 'Charlie'], name='Score')
print("--- pd.Series ---")
print(s)

# 2. 从 Python 字典创建二维 DataFrame
data = {
    'name': ['Alice', 'Bob', 'Charlie', 'David'],
    'age': [24, 29, 22, 31],
    'city': ['Beijing', 'Shanghai', 'Guangzhou', 'Beijing'],
    'score': [88.5, 92.0, np.nan, 95.5]
}
df = pd.DataFrame(data)
print("\\n--- pd.DataFrame ---")
print(df)
`}
</RunnableCodeBlock>

## 2. 常用高频 API 全景指南

在实际数据分析与机器学习预处理中，以下 8 大类 API 是使用频率最高的“基本功”：

### 2.1 数据导入与导出 (IO Operations)

| 操作分类 | 导入方法 (Read) | 导出方法 (Write) | 常用关键参数 |
| :--- | :--- | :--- | :--- |
| **CSV / TXT 文件** | `pd.read_csv('file.csv')` | `df.to_csv('out.csv', index=False)` | `encoding='utf-8'`, `sep=','`, `header=0` |
| **Excel 工作表** | `pd.read_excel('file.xlsx')` | `df.to_excel('out.xlsx')` | `sheet_name='Sheet1'` |
| **JSON / API 数据** | `pd.read_json('file.json')` | `df.to_json('out.json')` | `orient='records'` |
| **SQL 数据库** | `pd.read_sql(query, conn)` | `df.to_sql('table', conn)` | `if_exists='replace'` |

### 2.2 数据探查与结构概览

- `df.head(n)` / `df.tail(n)`：查看前 $n$ 行或后 $n$ 行数据（默认 5 行）。
- `df.info()`：输出数据框内存占用、每列非空值数量 (Non-Null Count) 与数据类型 (dtypes)。
- `df.describe()`：输出数值列的八项统计汇总（均值、标准差、最小值、四分位数、最大值）。
- `df.shape`：返回 `(行数, 列数)` 元组。
- `df.columns` / `df.index`：分别查看所有列名与行索引。

## 3. 数据检索与切片：loc 与 iloc 显式区分

这是初学 Pandas 时最容易混淆的坑点。Pandas 提供了两种精准切片索引器：

1. **`df.loc[行标签, 列标签]`**：基于**显式名称/标签 (Label-based)** 进行索引。包含起始和结束端点（闭区间 `[a, b]`）。
2. **`df.iloc[行位置, 列位置]`**：基于**0 开始的整数位置 (Integer Position-based)** 进行索引。遵循 Python 切片标准（前闭后开区间 `[a, b)`）。

<RunnableCodeBlock title="代码验证：loc 与 iloc 切片差异">
{`import pandas as pd

df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Charlie', 'David'],
    'age': [24, 29, 22, 31],
    'score': [88, 92, 79, 95]
}, index=['a', 'b', 'c', 'd'])

print("--- df.loc['a':'c', ['name', 'score']] ---")
print(df.loc['a':'c', ['name', 'score']])

print("\\n--- df.iloc[0:2, 0:2] ---")
print(df.iloc[0:2, 0:2])
`}
</RunnableCodeBlock>

## 4. 高频核心操作：条件筛选、缺失值与分组聚合

### 4.1 布尔条件筛选 (Boolean Indexing)

在 Pandas 中使用多个条件组合筛选时，必须遵守以下两条规则：
1. 逻辑与使用 `&`，逻辑或使用 `|`，逻辑非使用 `~`（**不能使用 Python 原生的 `and`, `or`, `not`**）。
2. 每个独立条件表达式**必须用小括号 `()` 括起来**！

```python
# 正确写法：年龄 > 25 且 分数 >= 90
high_performers = df[(df['age'] > 25) & (df['score'] >= 90)]

# 成员资格筛选 .isin()
beijing_shanghai = df[df['city'].isin(['Beijing', 'Shanghai'])]
```

### 4.2 缺失值处理 (Handling Missing Values)

数据缺失在实际 AI 任务中极常见。Pandas 使用 `NaN` (Not a Number) 表示缺失值：

- **检测缺失值**：`df.isnull().sum()`（统计每列缺失值总数）。
- **删除缺失值**：`df.dropna(subset=['score'])`（删除 score 列包含 NaN 的行）。
- **填充缺失值**：
  - 用固定常数填充：`df.fillna({'score': 0})`
  - 用均值/中位数填充：`df['age'].fillna(df['age'].mean(), inplace=True)`

### 4.3 分组聚合与透视表 (Groupby & Pivot Table)

`groupby` 遵循“拆分 (Split) - 应用 (Apply) - 合并 (Combine)”三步模式：

<RunnableCodeBlock title="代码实战：数据清洗、布尔筛选与 Groupby">
{`import pandas as pd
import numpy as np

df = pd.DataFrame({
    'city': ['Beijing', 'Shanghai', 'Beijing', 'Shanghai', 'Guangzhou', 'Beijing'],
    'department': ['HR', 'Tech', 'Tech', 'HR', 'Tech', 'HR'],
    'salary': [10000, 18000, 22000, 12000, 15000, np.nan],
    'experience': [2, 5, 7, 3, 4, 1]
})

# 1. 缺失值填充 (用薪资均值填充)
df['salary'] = df['salary'].fillna(df['salary'].mean())

# 2. 布尔筛选 (薪资 > 12000)
high_salary = df[df['salary'] > 12000]
print("--- 高薪员工 ---")
print(high_salary)

# 3. 按城市与部门做 Groupby 聚合统计
grouped = df.groupby('city').agg(
    avg_salary=('salary', 'mean'),
    count=('department', 'count')
)
print("\\n--- 按城市 Groupby 统计 ---")
print(grouped)
`}
</RunnableCodeBlock>

## 5. 多表合并：Concat 与 Merge

当需要将多个表格拼接到一起时：

1. **`pd.concat([df1, df2], axis=0)`**：简单拼接（`axis=0` 纵向按行堆叠，`axis=1` 横向按列拼接）。
2. **`pd.merge(df1, df2, on='key', how='inner')`**：类似于 SQL 中的 JOIN 关联（支持 `'inner'`, `'left'`, `'right'`, `'outer'`）。

```python
# 按照 user_id 做左连接 (Left Join)
merged_df = pd.merge(user_info, user_orders, on='user_id', how='left')
```
