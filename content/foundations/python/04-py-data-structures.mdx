# 04. 核心数据结构

选择正确的数据结构直接决定算法运行的时间复杂度。

```python
# 字典键的 O(1) 查找性能
sample_labels = {"cat": 0, "dog": 1, "bird": 2}
print("类别编码:", sample_labels.get("dog"))
```
