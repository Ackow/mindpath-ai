# 阶段 0.2-0.6 详细学习规划

> 对齐《AI学习路线与知识地图》中的 Python for AI 专项（PY01-PY12）。Python 专项负责工具使用；本规划负责让学习者理解这些工具背后的数学、数据纪律和实验工程。完成后，应能独立构建一个可复现的表格数据基线项目，并能解释其中的矩阵运算、损失函数、数据切分和评估结论。

## 使用方式

- **总周期**：24 周，每周 6-8 小时；按“阅读与手推 2 小时、编码复现 2-3 小时、练习与笔记 1-2 小时、项目复盘 1 小时”分配。
- **统一工作区**：沿用 Python 专项的虚拟环境。每周在 `notes/` 写一页概念笔记，在 `exercises/` 放可运行的 `.py` 或 Notebook，在 `tests/` 放至少一个可自动执行的断言或测试。
- **学习闭环**：先用纸笔或 Markdown 写出定义/推导，再用 NumPy 或 scikit-learn 验证；不要把库调用当作理解的替代品。所有随机实验传入显式 `random_state` 或 `numpy.random.Generator`。
- **进入下一阶段的门槛**：每个阶段的“验收”全部通过，且能在不看材料的情况下向别人解释一个核心图表或一段关键代码。

## 总览

| 周数 | 阶段 | 核心问题 | 阶段产出 |
|---:|---|---|---|
| 1-5 | 0.2 线性代数 | 数据与模型如何表示为向量和线性变换？ | PCA/低秩近似实验报告 |
| 6-10 | 0.3 微积分与优化 | 损失如何产生梯度，参数为何能更新？ | 从零实现线性回归与优化对比 |

| 21-24 | 0.6 实验与工程习惯 | 如何让结果可复现、可验证、可审阅？ | 可复现的端到端基线仓库 |

## 0.2 线性代数（第 1-5 周）

### 学习目标与 Python 衔接

掌握向量、矩阵、线性变换、正交投影、特征分解和 SVD；能辨别逐元素乘法与矩阵乘法、行向量与列向量、`shape` 不匹配等常见错误。该阶段直接服务于 PY08 NumPy，也为 PCA、线性回归、embedding 相似度和神经网络批量计算打基础。

| 周 | 概念与推导 | 编程实验 | 当周可交付物 |
|---:|---|---|---|
| 1 | 向量、矩阵、张量、维度；内积、范数、余弦相似度 | 用 NumPy 实现余弦相似度；比较 Python 循环与向量化 | `vector_ops.py`，含 shape 断言和 5 个自测样例 |
| 2 | 矩阵乘法、转置、秩、逆、迹；线性变换的几何含义 | 手写二维旋转、缩放、剪切并画出点云前后变化 | 一张变换可视化图及其解释 |
| 3 | 线性无关、基、列空间；正交性、Gram-Schmidt、最小二乘投影 | 用正规方程和 `numpy.linalg.lstsq` 拟合同一条直线 | 两种解法的参数与残差对照 |
| 4 | 特征值/特征向量、对角化、正定矩阵 | 验证 `Av = lambda v`；用协方差矩阵解释主方向 | 协方差椭圆与主轴图 |
| 5 | SVD、低秩近似、PCA 的方差最大化视角 | 对图片或二维数据做截断 SVD/PCA，比较重建误差 | `pca_from_scratch.ipynb` 与简短报告 |

**必做练习**

1. 解释 `(m, n) @ (n, k) -> (m, k)`，并给出批量样本 `X` 与权重 `w` 的形状。
2. 用投影公式求一点在一条向量上的投影，再用 NumPy 数值验证正交残差的内积约为 0。
3. 对同一数据比较保留 1、2、5 个奇异值时的重建误差；说明“解释方差高”不等于“因果重要”。

**推荐来源（按使用顺序）**

- [Mathematics for Machine Learning](https://mml-book.github.io/) 第 2、3、4、10 章：免费教材，作为定义和推导主线；对应公开仓库 [mml-book.github.io](https://github.com/mml-book/mml-book.github.io)。
- [MIT 18.06 Linear Algebra](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)：遇到子空间、投影、特征值概念不稳时选看对应课次，不要求完整刷完。
- [Immersive Linear Algebra](https://immersivemath.com/ila/index.html)：用动态图补足几何直觉，尤其是矩阵乘法和特征向量。
- [NumPy Linear algebra](https://numpy.org/doc/stable/reference/routines.linalg.html) 与 [NumPy tutorials](https://numpy.org/numpy-tutorials/)：只用于核对 API 和复现实验，不替代手推。

**验收**：不借助库函数写出余弦相似度、投影和 PCA 的关键步骤；能说明 SVD 与 PCA 的关系及为何训练集拟合得到的 PCA 不能直接在测试集重新 `fit`。

## 0.3 微积分与优化（第 6-10 周）

### 学习目标与 Python 衔接

理解导数是局部变化率、梯度是最陡上升方向，能从损失函数推出参数更新式；能诊断学习率、特征尺度、batch 大小对训练曲线的影响。它连接 PY05 函数设计、PY08 向量化和 PY11 中的训练循环。

| 周 | 概念与推导 | 编程实验 | 当周可交付物 |
|---:|---|---|---|
| 6 | 单变量导数、偏导、链式法则；计算图 | 对多项式和 sigmoid 做解析导数与有限差分校验 | `gradient_check.py`，输出相对误差 |
| 7 | 梯度、方向导数、Jacobian、Hessian；凸性直觉 | 在二维损失面画等高线与梯度箭头 | 一张含迭代轨迹的等高线图 |
| 8 | 梯度下降、批量/随机/mini-batch；收敛与学习率 | 从零实现线性回归的 batch GD 与 SGD | 固定种子的损失曲线对比 |
| 9 | Momentum、RMSProp、Adam；鞍点、病态条件数 | 在同一二次函数上比较四种优化器 | 参数轨迹、最终损失、步数表 |
| 10 | MSE、二元交叉熵、log-sum-exp 稳定性 | 从零实现 logistic regression；与 scikit-learn 对照 | 小型二分类报告与失败案例 |

**必做练习**

1. 使用中心差分检查梯度；当相对误差异常时先检查维度、符号和数值尺度。
2. 对未标准化与标准化特征分别训练线性回归，解释收敛速度差异。
3. 在训练集和验证集都记录 loss；禁止用测试集来选择学习率或迭代次数。

**推荐来源（按使用顺序）**

- [Mathematics for Machine Learning](https://mml-book.github.io/) 第 5、7、8、9 章：矩阵微积分与优化的主线。
- [3Blue1Brown: Essence of Calculus](https://www.3blue1brown.com/lessons/essence-of-calculus)：补充链式法则和梯度的动画直觉。
- [CS231n Optimization](https://cs231n.github.io/optimization-1/) 与 [Optimization 2](https://cs231n.github.io/optimization-2/)：阅读学习率、SGD、动量和 Adam 的工程解释。
- [NumPy random Generator](https://numpy.org/doc/stable/reference/random/generator.html)：实验一律使用 `default_rng(seed)`，避免全局随机状态污染。

**验收**：能从 `J(w) = mean((Xw-y)^2)` 推出梯度的形状；有限差分梯度检查通过；能用曲线证据解释一次不收敛是学习率问题、数据尺度问题还是实现错误。

## 0.4 概率与统计（第 11-15 周）

### 学习目标与 Python 衔接

用概率语言描述数据、模型预测和不确定性；理解为何高斯噪声常对应 MSE、伯努利标签常对应交叉熵。它为后续数据切分、指标置信区间、朴素贝叶斯、逻辑回归和模型评估提供依据。

| 周 | 概念与推导 | 编程实验 | 当周可交付物 |
|---:|---|---|---|
| 11 | 样本空间、随机变量、联合/边缘/条件概率、独立性、Bayes | 用模拟检验条件概率与 base-rate fallacy | `bayes_simulation.ipynb` |
| 12 | Bernoulli、Binomial、Gaussian、Poisson；期望、方差、协方差 | 采样并比较理论矩与样本矩 | 分布图与误差表 |
| 13 | 大数定律、中心极限定理、抽样分布、bootstrap | 逐步增加样本量，画均值分布收敛过程 | 可重复的 CLT/Bootstrap 图 |
| 14 | MLE、MAP、对数似然；高斯-MSE、伯努利-BCE 对应关系 | 用网格搜索画似然曲线，比较 MLE 和带先验的 MAP | 推导笔记与数值验证 |
| 15 | 置信区间、p 值、效应量、检验功效；多重比较风险 | 为模拟 A/B 测试报告差异和置信区间 | 一页 A/B 分析报告 |

**必做练习**

1. 区分 `P(A|B)`、`P(B|A)` 与独立；用一个医疗筛查或垃圾邮件例子验证 Bayes 更新。
2. 不调用现成统计检验函数，先通过重采样得到均值差的经验区间；之后再用 SciPy/Statsmodels 核对。
3. 写出高斯负对数似然到平方误差、伯努利负对数似然到二元交叉熵的每一步，明确常数项何时可省略。

**推荐来源（按使用顺序）**

- [OpenIntro Statistics](https://www.openintro.org/book/os/)：免费教材，作为概率、抽样和推断主线。
- [Think Stats 2](https://allendowney.github.io/ThinkStats2/) 及其 [公开仓库](https://github.com/AllenDowney/ThinkStats2)：用 Python 做模拟和重采样的练习来源。
- [scipy.stats](https://docs.scipy.org/doc/scipy/tutorial/stats.html)：在完成手写模拟后用于核对分布和统计 API。
- [Stanford CS229 notes](https://cs229.stanford.edu/main_notes.pdf)：第 1-4 节用于联系 MLE、MAP 和监督学习损失。

**验收**：给定一个二分类任务，能说明何时准确率会误导、为何需要看类别比例和置信区间；能用模拟解释“大样本下估计更稳定”而非只背诵定理。

## 0.5 数据处理与特征工程（第 16-20 周）

### 学习目标与 Python 衔接

把 PY09 pandas、PY10 可视化和 PY11 工作流落实成防泄漏的数据流程。重点不是堆砌特征，而是明确每列的语义、每次拟合的数据边界、每种切分是否符合真实预测场景。

| 周 | 数据纪律与概念 | 编程实验 | 当周可交付物 |
|---:|---|---|---|
| 16 | 数据字典；类型、缺失、重复、异常、标签质量；EDA 清单 | 对一个公开表格数据集做数据质量报告 | `data_audit.md` 与可复现 EDA Notebook |
| 17 | 随机/分层/分组/时间切分；训练、验证、测试职责 | 为分类、用户分组、时间序列各实现一种切分 | 切分策略选择说明 |
| 18 | 缺失值处理、数值缩放、类别编码；只在训练集 `fit` | 观察在全量数据拟合预处理导致的泄漏 | 泄漏与正确流程的指标对比 |
| 19 | 特征构造、选择、共线性、类别不平衡；业务可用性 | 建立原始、基础处理、特征增强三组基线 | 特征登记表和消融表 |
| 20 | `ColumnTransformer`、`Pipeline`、交叉验证；持久化 | 将前四周代码整理成单一 Pipeline | 端到端预处理脚本与测试 |

**建议数据集**

- 首选 [UCI Adult](https://archive.ics.uci.edu/dataset/2/adult)：同时包含数值、类别和缺失值，适合收入分类和公平性讨论。
- 备选 [OpenML Titanic](https://www.openml.org/search?type=data&status=active&id=40945)：规模小，适合快速迭代；必须说明它不代表真实线上分布。
- 使用 [scikit-learn datasets](https://scikit-learn.org/stable/datasets.html) 做 API 冒烟测试，不能把玩具数据当作项目结论的唯一证据。

**推荐来源（按使用顺序）**

- [pandas User Guide](https://pandas.pydata.org/docs/user_guide/index.html)：重点读 missing data、groupby、merge、categorical 和 time series；查询 API 时再读参考手册。
- [scikit-learn: Common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html) 与 [Pipeline](https://scikit-learn.org/stable/modules/compose.html)：以防数据泄漏为第一优先级。
- [scikit-learn: Cross-validation](https://scikit-learn.org/stable/modules/cross_validation.html)：按真实数据生成机制选择 `Stratified`、`Group` 或时间切分。
- [Feature Engineering for Machine Learning](https://github.com/alicezheng/feature-engineering-book)：公开配套仓库，用于特征思路和练习；其中的做法仍需用自己的数据边界验证。
- [Tidy Data](https://vita.had.co.nz/papers/tidy-data.pdf)：理解整洁数据的列/行/单元定义，帮助设计可维护的数据表。

**验收**：提交一份数据字典、一次 EDA、一套无泄漏的 `Pipeline` 和一次交叉验证结果。代码中不得在 split 前调用 `fit`、不得把 ID、未来信息或标签派生列作为特征；每个决定都写出理由。

## 0.6 实验与工程习惯（第 21-24 周）

### 学习目标与 Python 衔接

将 PY07 的文件/异常/测试和 PY11 的 AI 实验工作流合并为可审阅的最小项目。目标是使另一位开发者在干净环境中能复现结果，而非过早引入复杂的 MLOps 平台。

| 周 | 工程主题 | 实施任务 | 当周可交付物 |
|---:|---|---|---|
| 21 | 仓库结构、依赖、配置、随机性 | 建项目目录；锁定依赖；用 YAML/JSON 配置数据路径、seed、模型参数 | `README.md`、`requirements.txt` 或锁文件、示例配置 |
| 22 | 可测试的数据与代码 | 把加载、处理、训练、评估拆为函数；为 schema、切分和指标写测试 | `pytest` 可运行，至少 5 个有意义测试 |
| 23 | 实验记录与错误分析 | 记录运行命令、git commit、seed、数据版本/哈希、指标、图表；抽样检查误分类 | `runs/` 中一份结构化实验记录与错误分析 |
| 24 | 端到端复现与报告 | 在新虚拟环境从零运行；比较 dummy、线性和树模型；写限制与下一步 | 可复现项目仓库和最终报告 |

**最小仓库约定**

```text
project/
  README.md                 # 目标、数据来源/许可、运行步骤、限制
  requirements.txt          # 或受版本控制的锁文件
  configs/baseline.yaml     # seed、切分和模型超参数
  src/                      # load.py, features.py, train.py, evaluate.py
  tests/                    # 数据契约、特征、指标测试
  notebooks/                # 仅用于探索；结论回写到 src/ 和报告
  reports/                  # 图表、数据字典、实验结论
  .gitignore                # 数据、密钥、缓存和临时输出
```

**必须记录的实验字段**：数据来源 URL 与许可、下载日期或版本/哈希、代码 commit、Python/依赖版本、随机种子、切分规则、特征列表、超参数、指标、运行命令、失败或偏差说明。不要提交凭据、原始敏感数据或大体积模型文件。

**推荐来源（按使用顺序）**

- [Cookiecutter Data Science](https://cookiecutter-data-science.drivendata.org/) 与 [公开模板仓库](https://github.com/drivendataorg/cookiecutter-data-science)：借鉴目录职责，不必完整采用其工具链。

- [Python logging HOWTO](https://docs.python.org/3/howto/logging.html)：用结构化、分级日志代替散乱 `print`，但避免记录个人数据或密钥。

- [scikit-learn: Model persistence](https://scikit-learn.org/stable/model_persistence.html)：理解序列化的兼容性和安全边界，未受信任文件不可反序列化。

**验收**：在全新虚拟环境执行 README 中的一条或少量命令，得到同一量级的指标和报告图；测试通过；报告包含基线、误差样本、局限性和数据许可。若结果无法完全逐位一致，应说明硬件/并行计算导致的非确定性及可接受范围。

## 贯穿项目：公开表格数据基线

第 16 周确定数据集，第 24 周交付。建议选 Adult 或同等公开许可的表格数据，问题定义为“根据可在预测时刻获得的特征预测标签”。项目必须包含：

1. 数据卡：来源、许可、字段含义、目标变量、潜在偏差及不应用场景。
2. 数据审计：行数、类型、缺失率、重复率、类别分布和异常规则。
3. 无泄漏切分：说明为何选择分层、分组或时间切分。
4. 三个基线：`DummyClassifier`、逻辑回归、树模型；同一切分和相同评价指标下比较。
5. 评估与误差：混淆矩阵、主指标、置信区间或 bootstrap 区间、至少 10 个错误样本的分组分析。
6. 工程交付：配置文件、测试、固定 seed、依赖清单、图表和可从零运行的 README。
