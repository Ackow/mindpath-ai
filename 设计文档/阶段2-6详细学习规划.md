# 阶段 2-6 详细学习规划

> 本文承接阶段 1 的问题定义包。所有模型任务均使用固定的数据边界、切分、指标契约与实验记录；每次比较至少包含一个简单基线。建议每周投入 6-8 小时，按“原理与笔记、从零复现、库实现、项目复盘”循环学习。

## 总览

| 阶段 | 建议周期 | 核心产出 | 进入下一阶段的门槛 |
|---|---:|---|---|
| 2 监督学习 | 12 周 | 传统 ML 对比项目 | 能解释模型、指标、误差和取舍 |
| 3 评估与可靠性 | 5 周 | 可靠性评估报告 | 能选择正确验证策略并识别风险 |
| 4 无监督与推荐 | 8 周 | 推荐或无监督分析项目 | 能评估无标签结果而非仅画图 |
| 5 深度学习基础 | 10 周 | PyTorch 分类项目 | 能写训练循环、诊断并微调模型 |
| 6 可选专项 | 8-12 周 | 一个可演示的领域项目 | 能交付领域评估、限制与 README |

## 阶段 2：监督学习（12 周，7 章）

**阶段任务**：在同一个表格数据问题上，以 `Dummy`、线性模型、树模型和集成模型为候选，完成统一切分下的比较、调参与错误分析。先使用 scikit-learn，且至少对线性回归和逻辑回归完成一次 NumPy 从零实现。

| 章 / 周 | 知识点 | 必做任务 | 验收 |
|---|---|---|---|
| 2.1 第 1-2 周：线性回归 | 设计矩阵、残差、MSE、正规方程、梯度下降；线性假设、离群点、残差图 | 用 NumPy 实现一元/多元回归、正规方程与 GD；用 `LinearRegression` 核对；画残差与预测图 | 写清 `X`/`w` shape，两个实现参数与误差接近，能解释离群点影响 |
| 2.2 第 3 周：正则化线性模型 | 过拟合、Ridge/Lasso/Elastic Net、L1 稀疏和 L2 收缩、多项式特征、交叉验证 | 在 `Pipeline` 内比较无正则、Ridge、Lasso；只在训练折拟合缩放和特征扩展 | 用 CV 选择超参数；报告特征尺度、系数变化和验证差异 |
| 2.3 第 4-5 周：逻辑回归 | sigmoid、logit、最大似然、BCE、Softmax、概率、阈值、校准、类别权重 | 从零实现二分类 logistic regression；用 `LogisticRegression` 复现；画 PR/ROC/校准曲线 | 能从伯努利似然解释 BCE；阈值按代价/容量确定而非固定 0.5 |
| 2.4 第 6 周：kNN 与朴素贝叶斯 | 距离度量、k、特征缩放、维度灾难；条件独立、Gaussian/Multinomial/Bernoulli NB、平滑 | 比较不同 `k`、距离与缩放；在文本或计数特征上建 NB 基线 | 说明何时 kNN 预测昂贵、何时 NB 的独立假设会失效 |
| 2.5 第 7 周：SVM 与核方法 | 最大间隔、软间隔、hinge loss、`C`、支持向量、RBF/多项式核 | 用标准化数据比较线性 SVM、RBF SVM 和逻辑回归；限制搜索预算 | 解释 `C`、`gamma` 对边界与过拟合的影响，并报告训练成本 |
| 2.6 第 8-9 周：决策树 | 递归划分、Gini/熵、回归误差、深度、叶节点、剪枝、特征重要性限制 | 训练受限/未受限树；画树或规则；比较 permutation importance | 能指出单树过拟合证据，不将 impurity importance 当因果解释 |
| 2.7 第 10-12 周：集成学习 | bootstrap、bagging、OOB、随机森林；boosting、残差拟合、学习率、早停、XGBoost/LightGBM 边界 | 比较随机森林、Gradient Boosting 与一个简单模型；仅在验证集调参；完成最终测试与误差分析 | 报告性能、方差、训练成本、分组表现；测试集只评估一次 |

**阶段项目**：以阶段 1 的数据为主，完成“表格数据模型比较报告”。包含数据卡、固定切分、3 种以上基线、交叉验证表、最终测试结果、bootstrap 区间、混淆矩阵/残差图、至少 10 个错误样本与局限说明。

**参考**：[ISLR](https://www.statlearning.com/)（第 3-9 章）、[scikit-learn User Guide](https://scikit-learn.org/stable/user_guide.html)、[CS229 notes](https://cs229.stanford.edu/main_notes.pdf)、[XGBoost documentation](https://xgboost.readthedocs.io/)；先用 sklearn 完成实验，再接触 XGBoost/LightGBM 等专项库。

## 阶段 3：评估、泛化与可靠性（5 周，3 章）

**阶段任务**：对阶段 2 的最佳候选重新做评估审计。结论不再是“模型分数多少”，而是“该分数在何种数据边界、误差代价、群组和不确定性下可信到什么程度”。

| 章 / 周 | 知识点 | 必做任务 | 验收 |
|---|---|---|---|
| 3.1 第 1-2 周：评估与验证 | 混淆矩阵、Precision/Recall/F1、ROC-AUC/PR-AUC；MAE/MSE/RMSE/R2；留出、k 折、嵌套 CV、分层/分组/时间切分 | 为分类与回归各制作一份“指标选择卡”；比较随机、分组或时间切分；对主指标做 bootstrap 区间 | 能说明切分为何匹配数据生成机制，且不以单一 accuracy/R2 结论化 |
| 3.2 第 3 周：泛化与偏差-方差 | 欠拟合、过拟合、训练/验证误差、学习曲线、验证曲线、数据量、模型复杂度、正则化 | 画学习曲线与验证曲线；人为制造高偏差/高方差案例并给出修复方案 | 每项建议对应一项证据：增加数据、降复杂度、正则化或改特征 |
| 3.3 第 4-5 周：可解释性与可靠性 | permutation importance、PDP/ICE、SHAP 的用途和相关性陷阱；选择偏差、分布/概念漂移、公平性、隐私、数据授权 | 对关键分组报告指标和置信区间；做一份漂移/偏差/隐私风险登记表；选择一个解释样本 | 区分特征关联与因果；写出不可部署或需人工复核的条件 |

**阶段项目**：发布“模型可靠性卡”，至少包含数据范围、验证策略、主/约束指标及区间、分组表现、可解释性证据、已知失效情形、偏差/隐私/许可风险、监控信号和人工介入策略。

**参考**：[scikit-learn Model evaluation](https://scikit-learn.org/stable/modules/model_evaluation.html)、[scikit-learn Inspection](https://scikit-learn.org/stable/inspection.html)、[Google ML Crash Course: Fairness](https://developers.google.com/machine-learning/crash-course/fairness)、[Fairlearn](https://fairlearn.org/)、[Evidently data drift guide](https://docs.evidentlyai.com/docs/library/tests/data-drift)。

## 阶段 4：无监督学习与推荐系统（8 周，5 章）

**阶段任务**：掌握“没有标准标签时如何定义目标和验证结果”。聚类与降维是探索和表示工具，不应自动被解释为真实用户群体；推荐需区分离线排序与线上业务价值。

| 章 / 周 | 知识点 | 必做任务 | 验收 |
|---|---|---|---|
| 4.1 第 1-2 周：聚类 | K-means 初始化、分配-更新、SSE、局部最优、肘部法、轮廓系数、层次聚类、DBSCAN | 从零实现小型 K-means；对标准化前后、不同 `k`、不同 seed 比较；为每簇写画像 | 说明 `k` 的选择证据与稳定性，避免将簇编号当标签 |
| 4.2 第 3 周：概率聚类 | GMM、软分配、后验概率、EM、协方差形状、AIC/BIC、与 K-means 的关系 | 在非球形合成数据比较 GMM/K-means；画责任概率和决策边界 | 能解释软分配及模型选择，不将高概率误当确定身份 |
| 4.3 第 4-5 周：降维 | PCA 的协方差/SVD 视角、解释方差、重建、t-SNE/UMAP 的局部结构与随机性 | 用 PCA 做压缩与可视化；改变 t-SNE/UMAP 参数/seed；不以二维图证明类别可分 | 交付解释方差和重建误差；明确 t-SNE/UMAP 图的不可比较边界 |
| 4.4 第 6 周：异常检测 | 异常/噪声/新类别、统计阈值、Isolation Forest、One-Class SVM、不均衡评估 | 对已知异常数据比较阈值法和 Isolation Forest；按审查容量选择 top-K | 能给出调查闭环与误报成本，避免仅报告“检测到异常数” |
| 4.5 第 7-8 周：推荐与排序 | 用户-物品矩阵、显式/隐式反馈、内容推荐、协同过滤、矩阵分解、冷启动、召回-排序-重排、Recall@K/NDCG | 用 MovieLens 完成热门、内容或协同过滤中至少两种基线；按用户切分；比较 top-K | 报告冷启动、流行度偏差、离线指标限制与至少一个多样性/覆盖率指标 |

**阶段项目（二选一）**：

1. **客户/内容探索报告**：PCA + 聚类 + 簇稳定性分析，输出可行动假设而非给人贴标签。
2. **电影推荐原型**：MovieLens 数据上比较热门与协同过滤；报告 Recall@K、NDCG、覆盖率、冷启动限制和推荐样例。

**参考**：[scikit-learn Clustering](https://scikit-learn.org/stable/modules/clustering.html)、[scikit-learn Decomposition](https://scikit-learn.org/stable/modules/decomposition.html)、[UMAP documentation](https://umap-learn.readthedocs.io/)、[MovieLens datasets](https://grouplens.org/datasets/movielens/)、[Microsoft Recommenders](https://github.com/recommenders-team/recommenders)。

## 阶段 5：深度学习基础（10 周，6 章）

**阶段任务**：用 PyTorch 实现、训练、调试和评估一个分类模型。先理解 tensor、计算图与训练循环，再使用预训练模型；不直接跳到大模型微调。

| 章 / 周 | 知识点 | 必做任务 | 验收 |
|---|---|---|---|
| 5.1 第 1-2 周：神经元与 MLP | 感知机、线性不可分、MLP、激活函数、初始化、宽度/深度 | 用 NumPy 实现两层 MLP 前向计算；在二维 toy data 比较线性与 MLP 边界 | 能说明非线性激活的作用和各层 tensor shape |
| 5.2 第 3 周：前向与反向传播 | 计算图、链式法则、损失、autograd、梯度检查、梯度消失/爆炸 | 手推小网络反传；与 autograd 比较；完成梯度检查 | 理解 `.backward()`、梯度累积和 `no_grad()`，数值检查通过 |
| 5.3 第 4-5 周：优化与训练循环 | SGD/Momentum/RMSProp/Adam/AdamW、batch/epoch、scheduler、warmup、weight decay、checkpoint | 规范训练/验证循环；记录 loss/metric；比较 SGD 和 AdamW；保存 best checkpoint | 可恢复模型并在独立测试集评估；能从曲线诊断训练失败 |
| 5.4 第 6 周：正则化与迁移 | dropout、BatchNorm/LayerNorm、早停、数据增强、label smoothing、预训练/冻结/微调 | 在同一数据比较至少两项正则化；冻结后再逐步解冻预训练骨干 | 报告过拟合证据、增强边界和迁移前后成本/收益 |
| 5.5 第 7-8 周：PyTorch 实现 | Tensor、Dataset、DataLoader、`nn.Module`、device/dtype、保存加载、推理模式 | 将项目拆为数据、模型、训练、评估模块；写 CPU 可跑的最小测试 | 无全局状态/Notebook 隐含依赖；训练与推理预处理一致 |
| 5.6 第 9-10 周：表示学习与 embedding | embedding、相似度检索、词/类别嵌入、对比学习与自监督直觉 | 训练或使用 embedding 做近邻检索；展示成功/失败近邻 | 不把 embedding 距离直接解释为因果或事实正确性 |

**阶段项目**：完成图像或文本分类。提交训练曲线、验证/测试指标、混淆矩阵、错误样本、可复现 checkpoint、CPU 推理脚本，以及从头训练与迁移学习的比较。

**参考**：[PyTorch Tutorials](https://docs.pytorch.org/tutorials/)、[PyTorch Recipes](https://docs.pytorch.org/tutorials/recipes/recipes_index.html)、[Dive into Deep Learning](https://d2l.ai/) 及其 [仓库](https://github.com/d2l-ai/d2l-en)、[CS231n](https://cs231n.stanford.edu/)。

## 阶段 6：选择一个专项（8-12 周）

**选择规则**：只选 A-D 中一条作为主线。选择前写下目标岗位/作品方向、可用算力、数据许可和最终 Demo；其余方向保留为概览，不并行开项目。所有专项均须在阶段 3 的可靠性框架下评估。

### 6A 计算机视觉（8-10 周，4 章）

| 章 | 知识点 | 必做任务与交付 |
|---|---|---|
| CNN 基础 | 图像张量、卷积、padding、stride、池化、感受野、特征图 | 手算输出尺寸；用 PyTorch 搭建小型 CNN；可视化特征图并说明局限 |
| 视觉骨干 | ResNet、DenseNet、EfficientNet、ViT、预训练与迁移 | 对同一数据比较小 CNN 与预训练 ResNet/ViT；报告参数量、速度和精度 |
| 视觉任务 | 分类、多标签、检测 IoU/NMS/mAP、分割 IoU/Dice、OCR/关键点概览 | 选一个任务完成数据、训练、指标和错误样本；不跨任务堆叠 |
| 数据与部署 | 增强、标注噪声、分组切分、量化、延迟、鲁棒性 | 对光照/裁剪/压缩等扰动做鲁棒性评估；交付推理脚本与模型卡 |

**项目**：可复现的图像分类、检测或分割项目，必须保留数据许可、标注说明、每类指标和失败样例。参考：[PyTorch Vision](https://pytorch.org/vision/stable/index.html)、[CS231n](https://cs231n.stanford.edu/)、[MMDetection](https://github.com/open-mmlab/mmdetection)。

### 6B NLP、Transformer 与 LLM（10-12 周，6 章）

| 章 | 知识点 | 必做任务与交付 |
|---|---|---|
| 传统 NLP | 分词、n-gram、TF-IDF、NB、词向量、分类/检索/摘要边界 | 建 TF-IDF + 线性/NB 文本基线，报告数据清洗和错误样本 |
| 序列模型 | RNN、BPTT、LSTM/GRU、seq2seq、teacher forcing、beam search | 阅读并运行最小序列建模示例；解释长程依赖局限 |
| Transformer | 位置编码、Q/K/V、多头注意力、残差、LayerNorm、encoder/decoder、因果掩码 | 实现或逐步追踪一个 attention 前向；标注每个 tensor shape |
| 语言模型推理 | MLM/CLM、BPE/WordPiece、temperature、top-k/top-p、KV cache、幻觉 | 比较不同采样参数；建立事实性/格式/延迟的评估样本集 |
| 微调与对齐 | 指令微调、PEFT/LoRA、RLHF/DPO 概览、自动/人工评测、安全与版权 | 对小模型或公开 checkpoint 做受限 LoRA 实验；记录许可证、数据来源与风险 |
| RAG 与 Agent | 切块、embedding、检索、重排、引用、工具调用、记忆、权限 | 先做关键词检索，再做向量检索；回答必须带来源引用；工具调用采用最小权限 |

**项目**：为本知识库实现带章节引用的问答原型，比较关键词与向量检索的召回/回答质量，并建立无法回答、无引用和注入攻击样例。参考：[Hugging Face LLM Course](https://huggingface.co/learn/llm-course/)、[Transformers docs](https://huggingface.co/docs/transformers/)、[Sentence Transformers](https://www.sbert.net/)、[RAGAS](https://docs.ragas.io/)。

### 6C 强化学习（8-10 周，4 章）

| 章 | 知识点 | 必做任务与交付 |
|---|---|---|

**项目**：在 Gymnasium 离散环境完成可复现代理对比，至少报告不同随机种子、平均回报和失败策略。参考：[OpenAI Spinning Up](https://spinningup.openai.com/)、[Gymnasium](https://gymnasium.farama.org/)、[CleanRL](https://github.com/vwxyzjn/cleanrl)。

## 通用完成标准

- 每章至少产出一份概念笔记、一个可运行示例和 3-5 道自测题。
- 每个项目都有数据来源与许可、固定切分、基线、配置、依赖、测试和 README。
- 所有结论报告指标、不确定性或跨 seed 波动、错误样本和局限；不以单次最高分作为结论。
- 未通过验收时回到相应阶段补数据定义、数学基础或工程流程，而不是直接更换复杂模型。
